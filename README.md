# Python Quiz Application

A simple interactive Quiz Application built using Python. It loads multiple-choice questions from a JSON file, checks user answers, and calculates the final score.

## Features

- 50 Python-related MCQ questions
- Questions loaded from a JSON file
- Four multiple-choice options
- Input validation
- Exception handling
- Correct and incorrect answer feedback
- Automatic score calculation
- Terminal-based user interface

## Technologies Used

- Python
- JSON
- Exception Handling
- Loops and Conditional Statements

## Project Structure

```text
Quiz-Application/
├── main.py
├── question.json
└── README.md
```

## How to Run

1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Run the following command:

```bash
python main.py
```
